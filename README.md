🌙 Website Dark Mode

A simple and responsive website with Light Mode & Dark Mode toggle functionality built using HTML, CSS, and JavaScript.

This project demonstrates how to switch themes dynamically with smooth styling and icon changes.

🧠 How It Works

The theme toggle button listens for a click event.

A CSS class (like dark-mode) is added/removed from the body.

Styles automatically change using CSS selectors.

The theme icon also updates dynamically.

Example logic:

icon.onclick = function() {
    document.body.classList.toggle("dark-mode");
}
